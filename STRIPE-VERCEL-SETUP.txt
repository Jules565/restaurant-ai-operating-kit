RESTAURANT AI OPERATING KIT — STRIPE / VERCEL SETUP

1. Keep STRIPE_SECRET_KEY in Vercel Project Settings as a Production environment variable.
2. Do NOT put the Stripe secret key in GitHub, HTML, JavaScript, or config.json.
3. After changing environment variables, redeploy the Vercel project.
4. The checkout creates a one-time EUR 29 Stripe Checkout Session.
5. Stripe redirects to /api/stripe-success?session_id=... after payment.
6. That server endpoint verifies payment_status=paid and the EUR 29 amount, then issues a signed one-year HttpOnly access cookie.
7. middleware.js blocks direct access to /app.html unless that cookie is valid.
8. IMPORTANT: make the GitHub repository PRIVATE before launch, because the repository contains the app source code.
9. Test in Stripe Test mode before switching the deployment to live payments.
